# Obsidian SEO Audit

**SEO Audit** — плагін для Obsidian, який допомагає перевіряти SEO-метадані вебсторінок безпосередньо зі своїх нотаток.

Якщо ви ведете документацію сайту, працюєте з блогом або керуєте великою кількістю вебсторінок, SEO Audit дозволяє зібрати їхні адреси в одному місці, перевірити опублікований HTML і переглянути результати у зручній таблиці.

Плагін автоматично знаходить URL у властивостях Markdown-нотаток. Вам достатньо вибрати сторінки та запустити перевірку.

Усі результати зберігаються локально. **Вміст нотаток залишається незмінним.**

## Можливості
- **Автоматичний пошук сторінок.** Збирає URL із властивостей Markdown-нотаток.
- **Перевірка SEO-метаданих.** Аналізує заголовки, описи, canonical, robots, Open Graph і Twitter Cards.
- **Мовні версії сторінок.** Знаходить усі alternate/hreflang посилання.
- **Аналіз H1.** Показує основні заголовки сторінки та їхню кількість.
- **HTTP-діагностика.** Перевіряє статус відповіді, час завантаження та X-Robots-Tag.
- **Довжина метаданих.** Відображає кількість символів для подальшого аналізу.
- **Зручна таблиця.** Пошук, сортування, фільтри та налаштування стовпців.
- **Вибіркове сканування.** Можна перевірити всі сторінки або лише потрібні.
- **Експорт результатів.** Збереження даних у CSV та JSON.
- **Багатомовний інтерфейс.** Підтримка української та англійської мов.

## Як користуватися

### 1. Додайте URL до нотатки
Відкрийте Markdown-нотатку та додайте до її властивостей адресу вебсторінки:

```yaml
---
title: My website page
url: https://example.com/page
---
```

SEO Audit автоматично знайде URL і додасть сторінку до таблиці перевірок.
**Кожна нотатка може містити лише один URL у відповідній властивості.** Якщо властивість відсутня або містить некоректну адресу, нотатка не включається до списку сторінок.
Назву властивості `url` можна змінити в налаштуваннях плагіна.

### 2. Відкрийте SEO Audit
Натисніть іконку **SEO Audit** на бічній панелі Obsidian або скористайтеся командою **Відкрити SEO Audit**.
Відкриється таблиця з усіма знайденими вебсторінками.
Кожна адреса відображається лише один раз, навіть якщо вона зустрічається в кількох нотатках. При цьому зберігаються посилання на всі відповідні файли.

### 3. Запустіть перевірку

Натисніть **Перевірити всі**, щоб проаналізувати всі знайдені вебсторінки.
Для вибіркової перевірки позначте потрібні рядки та натисніть **Перевірити вибрані**.
Під час сканування відображається прогрес. За потреби перевірку можна зупинити.
Сканування запускається лише вручну. Плагін не надсилає запити до вебсайтів автоматично при запуску Obsidian.

### 4. Перегляньте результати
Після завершення сканування таблиця відображатиме отримані дані.
Можна шукати сторінки за адресою, назвою нотатки або метаданими, сортувати результати, застосовувати фільтри та вибирати потрібні стовпці.
Натисніть на рядок, щоб відкрити детальну інформацію про сторінку.
У детальному перегляді можна побачити:

| Категорія | Дані |
|---|---|
| Основні метадані | Title, Description, Canonical, Robots |
| Open Graph | OG Title, Description, Image |
| Twitter Cards | Twitter Title, Description, Image |
| Мовні версії | Усі alternate/hreflang, включно з x-default |
| Заголовки | Усі H1 та їхня кількість |
| HTTP | Код відповіді, час отримання, X-Robots-Tag |

Для метаданих також показується довжина значень у символах. Якщо певний тег зустрічається кілька разів, можна переглянути всі його значення.
Плагін допомагає знаходити відсутні метадані, HTTP-помилки та інші особливості сторінок.

### 5. Відкрийте сторінку або нотатку

Із результатів перевірки можна:
- Відкрити опубліковану вебсторінку у браузері.
- Перейти до відповідної Markdown-нотатки в Obsidian.

Це дозволяє швидко знаходити вихідні матеріали для сторінок, які потребують перевірки.

### 6. Експортуйте результати
SEO Audit підтримує експорт у два формати:

- **CSV** — для роботи з таблицями, наприклад в Excel або Google Sheets.
- **JSON** — для програмного аналізу та обробки даних.

Експорт містить результати для всіх сторінок поточного списку, незалежно від застосованих фільтрів.

## Налаштування
Відкрийте **Settings → Community plugins → SEO Audit**.

| Налаштування | За замовчуванням |
|---|---|
| Назва властивості URL | `url` |
| Одночасні запити | 3 |
| Таймаут запиту | 30 секунд |
| Мова інтерфейсу | Автоматично |

Можна змінити властивість, у якій зберігаються URL, налаштувати швидкість сканування та вибрати мову інтерфейсу.

Підтримуються адреси HTTP та HTTPS.

## Встановлення
Для роботи потрібен **Obsidian 1.13.0 або новіший**.

1. Завантажте файли `main.js`, `manifest.json` і `styles.css` з випуску плагіна.
2. Створіть папку `.obsidian/plugins/seo-audit/` у своєму Vault.
3. Скопіюйте до неї завантажені файли.
4. Перезапустіть Obsidian.
5. Відкрийте **Settings → Community plugins** та увімкніть **SEO Audit**.

Після встановлення плагін готовий до використання.

## Важлива інформація
**Звідки беруться результати?**
Плагін завантажує HTML опублікованої вебсторінки та аналізує його метадані. Якщо сайт додає певні елементи лише після виконання JavaScript, вони можуть бути недоступними для аналізу.

**Чи змінюються мої нотатки?**
Ні. Плагін лише читає URL із властивостей нотаток. Усі результати перевірки зберігаються окремо.

**Чи потрібно перевіряти сторінки повторно?**
Так. Результати відповідають стану сторінки на момент останнього сканування. Щоб отримати актуальні дані, запустіть перевірку ще раз.

**Чи зберігається історія перевірок?**
Поки що ні. Повторне сканування оновлює збережений результат сторінки.

**Чи перевіряє плагін відповідність рекомендаціям Google?**
Наразі плагін збирає SEO-метадані та їхні довжини, але не встановлює автоматичних оцінок відповідності рекомендаціям пошукових систем.

**Що означає час відповіді?**
Це час від початку HTTP-запиту до повного отримання відповіді від сервера. Він не є показником TTFB або оцінкою швидкодії сторінки для користувача.
